# Borrador Nebula archivado

Estos dos archivos proceden de un experimento visual encontrado durante la
retoma del 9 de octubre de 2026. Se conservan completos como texto para poder
recuperar las ideas sin incorporarlas a los source sets Kotlin.

El borrador no compilaba: sustituía contratos del tema usados por las pantallas,
incluía parámetros inexistentes de Compose y contenía sintaxis inválida.
El tema activo vuelve a ser el tema funcional del último commit.

Para retomarlo, portar componentes individualmente y verificar Android y Desktop.
No copiar estos archivos directamente a commonMain.
